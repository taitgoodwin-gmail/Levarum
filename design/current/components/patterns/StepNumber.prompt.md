A numeral in a 1.5px circle. Levarum draws no icons, so numbered circles carry sequence everywhere.

```jsx
<StepNumber n={1} />                    {/* 34px, petrol tint — page steps */}
<StepNumber n={2} size={28} tone="ink" />  {/* in a list on a white card */}
```

Pair with a short time estimate beside it ("About 90 seconds", "Fifteen minutes, if you want it") rather than a label like "Step 1".
