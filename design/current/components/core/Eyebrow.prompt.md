The tracked-caps label that sits above almost every heading and inside most cards. 13px, Schibsted Grotesk 600, uppercase.

```jsx
<Eyebrow wide>WHAT WE AUTOMATE</Eyebrow>
<Eyebrow tone="quiet">TODAY</Eyebrow>
```

Write these editorially, not taxonomically — `WHAT IT LOOKS LIKE ON A TUESDAY`, `PROOF, HONESTLY`, `RANKED BY HOURS GIVEN BACK`. Use `·` to join two facts: `ROOFER · TWO VANS`. `wide` (0.08em) for page-level eyebrows, default (0.06em) inside cards.
