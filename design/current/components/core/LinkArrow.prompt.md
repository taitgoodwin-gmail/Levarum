The onward link — "read more" as a full phrase with a trailing `→`, never a chevron icon.

```jsx
<LinkArrow href="/what-we-automate">All five jobs, with a week from each</LinkArrow>
<LinkArrow href="/partners" quiet>Put your name down</LinkArrow>
```

Pass the label only; the arrow is appended. Hover changes colour only — no underline ever appears. Always at least 44px tall so it is a real touch target.
