Status and context pills. Fully rounded, 13px tracked caps, always tinted-fill-plus-border.

```jsx
<Pill tone="new">NEW</Pill>
<Pill tone="booked">BOOKED</Pill>
<Pill dot>OWNER-RUN BUSINESSES · ANYWHERE IN THE US</Pill>
```

Colour is never the only carrier — the label always says the state in words too. Forest (`booked`) is the system's only positive colour and exists for this one use.
